About

I'm a software developer and student at Vasireddy Venkatadri Institute of Technology, working across the backend of both Python and Java. I like turning tedious, manual work into scripts and services that run on their own — whether that's a Selenium bot filling out forms or a Spring Boot API serving a production app.

My work spans two directions: building APIs (Spring Boot, Spring Security, FastAPI) and automating processes (Selenium, pandas, RPA pipelines). I'm comfortable moving between the two, and I care about projects that actually ship — several of mine are live and deployed, not just sitting in a repo.
